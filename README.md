# Job Application Assistant

A personal job application tool built with Next.js 16, React 19, and TypeScript. Paste a job description and get a tailored CV summary and cover letter generated by Claude AI — then export as a `.docx` file and upload it directly to Google Drive.

## Features

- **Generate tab** — paste a job description, choose to generate a tailored CV, a cover letter, or both. Claude (Sonnet 4.6) rewrites only the dynamic sections (position title, summary, skills order, projects order) while leaving your base experience and education untouched.
- **Profile tab** — manage your full profile: contact details, photo, experience, projects, education, languages, and skills. Stored locally in `localStorage`.
- **Tracker tab** — log every application with company, role, status (`draft → applied → interview → offer → rejected`), notes, and a link. Star and filter entries.
- **DOCX export** — generated documents are assembled into a `.docx` file via the `/api/docx` route and downloaded in one click.
- **Google Drive upload** — the DOCX is uploaded to a configured Drive folder via a service-account-backed `/api/drive` route.

## Tech stack

| Layer | Library |
|---|---|
| Framework | Next.js 16 (App Router) |
| UI | React 19, Tailwind CSS v4 |

| Document | `docx` |
| Storage | Google APIs (Drive) |
| Language | TypeScript 5 |

## Getting started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy the template and fill in your keys:

```bash
cp .env.local.example .env.local   # or create .env.local manually
```

Required variables:

```env
ANTHROPIC_API_KEY=sk-ant-...

GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_REFRESH_TOKEN=...
GOOGLE_DRIVE_FOLDER_ID=...
```

> **Google Drive note:** the target folder must be a **Shared Drive** folder shared with your service account. Personal "My Drive" folders do not work with service accounts.

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### 4. Build for production

```bash
npm run build
npm start
```

## API routes

| Route | Method | Purpose |
|---|---|---|
| `/api/generate` | POST | Generate tailored CV fields and/or cover letter via Claude |
| `/api/docx` | POST | Build and return a `.docx` document |
| `/api/drive` | POST | Upload a base64-encoded file to Google Drive |

## Data persistence

Profile and application data are stored in **browser `localStorage`** — no database required. Clearing site data will erase your entries.
